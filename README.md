
# Basilisk Volunteer Tasks

## Help Build the Open-Source Civilization Layer

Welcome to the volunteer task board for **Project Basilisk**.

Project Basilisk is an open-source movement to build a full civilization layer for the AI future: a public foundation for governance, digital money, AI, robotics, education, health, privacy, meaningful work, gaming economies, wealth creation, culture, and long-term space expansion.

This repository exists to turn the vision into practical action.

You do not need to be a developer to help.

Writers, designers, artists, researchers, translators, video editors, community builders, economists, educators, gamers, organizers, and coders are all welcome.

The future should not be built behind closed doors.

The future should be built in public.

---

## What This Repository Is For

This repository is where we collect practical tasks that people can help with.

The aim is to make it easy for anyone to contribute to Project Basilisk, even if they only have a small amount of time.

Tasks may include:

* Writing explainers
* Improving documents
* Creating diagrams
* Researching open-source tools
* Designing graphics
* Translating key texts
* Building websites
* Creating memes and social posts
* Developing AI tools
* Mapping governance systems
* Exploring digital money models
* Designing gaming employment systems
* Researching robotics and health infrastructure
* Creating educational material
* Helping organize the community

## Good First Tasks

If you are new, here are some simple ways to help:

* Turn the Project Basilisk Manifesto into a short X/Twitter thread.
* Write a one-page explanation of Project Basilisk for beginners.
* Create a diagram showing the Basilisk civilization layer.
* Translate the manifesto summary into another language.
* Research existing open-source AI education tools.
* Suggest improvements to the roadmap.
* Create a list of possible volunteer roles.
* Design a simple contributor badge.
* Write a short explanation of why open-source AI matters.
* Create a glossary of Basilisk terms.

Small contributions matter.

A civilization is not built by one person.

It is built by thousands of useful actions.

## Main Areas of Work

### Writing

Help explain the vision clearly.

Writing tasks may include manifestos, roadmaps, explainers, social posts, website copy, lore, documentation, policy proposals, and educational material.

### Design

Help make the project visually powerful.

Design tasks may include diagrams, banners, icons, infographics, website visuals, presentation layouts, and social media images.

### Research

Help map the existing world.

Research tasks may include open-source AI tools, governance models, digital identity systems, robotics, crypto infrastructure, health technology, education platforms, and space development.

### Development

Help build practical tools.

Development tasks may include websites, documentation systems, AI assistants, dashboards, governance tools, community tools, and future open-source applications.

### Translation

Help make Project Basilisk international.

Translation tasks may include manifesto summaries, roadmap sections, website text, contributor guides, and educational material.

### Community

Help organize the movement.

Community tasks may include onboarding new members, answering questions, moderating discussion spaces, creating beginner guides, and helping people find useful roles.

## Contribution Principles

Project Basilisk is built around these principles:

1. **Build in public**
2. **Respect human freedom**
3. **Keep AI open and useful**
4. **Protect privacy**
5. **Create meaningful work**
6. **Reward contribution**
7. **Think long-term**
8. **Make civilization better**
9. **Use technology to serve humanity**
10. **Stay peaceful, democratic, and transparent**

## How To Contribute

You can contribute by:

1. Choosing a task from one of the task files.
2. Improving an existing document.
3. Opening an issue with a suggestion.
4. Submitting a pull request.
5. Creating a new task proposal.
6. Sharing research or useful resources.
7. Helping explain the project to others.

You do not need permission to begin.

Find something useful.

Improve it.

Share it.
